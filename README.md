# Argos Press - تطبيق ويب (WebView)

تطبيق أندرويد بسيط يعرض الموقع: https://argos-press.onrender.com

## الأذونات المفعّلة
- الكاميرا (لرفع الصور / التقاط صورة مباشرة)
- تخزين الملفات (رفع وتحميل الملفات)
- الإشعارات (Android 13+)

## طريقة البناء (بدون Android Studio)
1. أنشئ ريبو جديد على GitHub.
2. ارفع كل ملفات هذا المجلد كما هي (حافظ على نفس هيكلية المجلدات، وخصوصًا مجلد `.github/workflows`).
3. روح على تبويب **Actions** في الريبو، شغّل الـ workflow يدويًا (Run workflow) أو فقط اعمل push - راح يشتغل تلقائيًا.
4. بعد ما يخلص البناء (٣-٥ دقائق تقريبًا)، افتح آخر run، وبتلاقي ملف APK جاهز تحت قسم **Artifacts** باسم `argos-press-apk`.
5. حمّل الملف، فك الضغط (zip)، وثبّت ملف `app-debug.apk` على جوالك.

## ملاحظات
- الأيقونة مأخوذة من شعار ARGOS اللي أرسلته.
- التطبيق حاليًا يبني نسخة Debug (للتجربة والتثبيت المباشر). لو تبي نسخة Release موقّعة تنشرها على متجر جوجل بلاي، قلي وأضيف لك خطوة توقيع (signing) في الـ workflow.
